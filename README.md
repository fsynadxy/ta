# 烬土防线 · EMBERLINE

一款原创的**网格部署式塔防**网页游戏：把干员部署到地图格子上，选择朝向，用近战干员阻挡敌人、用高台上的远程干员输出与治疗，守住防御点。

所有角色、敌人、关卡与美术都是原创的，用 Canvas 绘制，不依赖任何图片或第三方库。

## 怎么玩

- **直接打开**：双击 `index.html` 就能在浏览器里玩，不需要安装或构建。
- **本地服务器（可选）**：`python3 -m http.server 8000`，然后访问 <http://localhost:8000>。
- **手机**：支持触屏，建议横屏。

### 操作

| 操作 | 方式 |
| --- | --- |
| 部署 | 把下方干员卡拖到发光的格子上（或先点卡片、再点格子） |
| 朝向 | 放下后向某个方向拖动并松开；键盘可用方向键 + 回车 |
| 技能 / 撤退 | 点击场上的干员，在弹出的轮盘里操作 |
| 暂停 / 倍速 | 左上角按钮，或 `空格` / `F` |
| 取消 | `Esc`、右键，或点提示条上的「取消」 |

拖动卡片、选择朝向或查看干员时，战斗会自动放慢（子弹时间），方便从容决策。

### 核心规则

- **部署点数（DP）**：每秒恢复 1 点，部署干员需要消耗。场上干员数量有上限。
- **地面与高台**：近战干员只能部署在地面，远程干员只能部署在高台。
- **阻挡**：地面干员会拦住进入其格子的敌人，直到阻挡数用完；飞行敌人无法被阻挡，近战干员也无法攻击它们。
- **伤害类型**：物理伤害受防御削减（最低保留 5%），法术伤害按法抗百分比削减。重甲敌人请用法术处理。
- **撤退**：返还一半费用，进入再部署冷却；阵亡不返还。
- **评价**：无漏怪 3★，损失不超过 3 点生命 2★，其余通关 1★。通关后解锁下一关，进度保存在浏览器本地。

### 关卡

1. **拂晓前哨**：教学关，单条通道。
2. **断桥**：两路汇合，出现飞行敌人。
3. **雾港回廊**：蜿蜒回廊，有远程咒术者和首领「巨像」。
4. **终焉堡垒**：三个入口同时进攻，两名巨像。

## 项目结构

```
index.html        页面结构与界面
style.css         样式（含手机/窄屏适配）
js/data.js        干员、敌人、关卡数据（地图用字符画描述）
js/engine.js      游戏逻辑：寻路、阻挡、攻击、技能、波次（不依赖 DOM）
js/render.js      Canvas 2.5D 渲染与特效
js/main.js        输入、HUD、菜单、音效与主循环
tools/check.js    关卡自检脚本
```

### 自检

```
node tools/check.js
```

脚本会校验每张地图与敌人路线，并用三套脚本化部署方案模拟每一关：不部署必须失败，完整方案必须通关，简陋方案不能三星，以此确认关卡既能通过又有挑战性。

### 添加关卡

在 `js/data.js` 的 `LEVELS` 中追加一项：用字符画写 `map`（`#` 墙、`.` 地面、`,` 不可部署道路、`h` 高台、`R` 入口、`P` 防御点），在 `routes` 中用途经点描述敌人路线（相邻途经点之间会自动寻路），在 `waves` 中按时间配置出怪。然后在 `tools/check.js` 里补一套部署方案，运行自检确认可玩。
